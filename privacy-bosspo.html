Kebijakan Privasi ini menjelaskan bagaimana aplikasi BossPo mengakses, menggunakan, menyimpan, dan membagikan data saat pengguna memakai fitur aplikasi.

1. Data yang diproses

BossPo dapat memproses data yang dimasukkan sendiri oleh pengguna, antara lain:

  • nama pelanggan;
  • nomor WhatsApp atau nomor telepon pelanggan;
  • nama barang, jumlah/qty, harga beli, harga jual, keuntungan, status pembayaran, dan kembalian;
  • tanggal, waktu, dan riwayat transaksi;
  • data Open PO, belanja bakul, COD, serta laporan usaha;
  • foto produk, katalog, atau bukti transaksi yang dipilih atau dibuat oleh pengguna.

2. Tujuan penggunaan data

Data tersebut digunakan hanya untuk menjalankan fungsi BossPo, seperti:

  • mencatat dan mengelola pesanan;
  • menghitung modal, penjualan, keuntungan, dan laporan;
  • menampilkan riwayat transaksi;
  • membuat daftar belanja bakul dan rincian COD;
  • membuat file laporan atau backup;
  • membantu pengguna menghubungi pelanggan atau membagikan informasi melalui aplikasi lain atas tindakan pengguna.

3. Penyimpanan data

Pada versi aplikasi ini, data utama BossPo disimpan secara lokal pada perangkat pengguna. BossPo tidak secara otomatis mengirim database pesanan ke server milik BossPo.

Sistem Android pada perangkat pengguna dapat melakukan pencadangan aplikasi sesuai pengaturan akun/perangkat Android yang digunakan. Pengelolaan pencadangan sistem tersebut berada di bawah kontrol pengguna dan penyedia sistem perangkat.

4. Kamera, galeri, dan foto

Fitur kamera atau pemilih foto digunakan hanya ketika pengguna memilih fungsi yang membutuhkan gambar. Foto dapat digunakan untuk katalog/Open PO, bukti transaksi, atau fungsi lain yang dipilih pengguna. BossPo tidak mengambil foto secara diam-diam.

5. WhatsApp dan aplikasi pihak ketiga

BossPo dapat membuka WhatsApp atau menu berbagi Android untuk mengirim teks, nomor tujuan, atau gambar yang telah dipilih pengguna. Pengiriman hanya terjadi setelah tindakan pengguna. Setelah data diteruskan ke aplikasi pihak ketiga, pemrosesan selanjutnya mengikuti kebijakan privasi aplikasi pihak ketiga tersebut.

6. Laporan Excel, ekspor, dan backup

BossPo dapat membuat file laporan, termasuk file Excel, serta file backup berdasarkan data yang tersimpan di perangkat. Lokasi penyimpanan atau tujuan berbagi dipilih oleh pengguna. Pengguna bertanggung jawab menjaga keamanan file yang telah diekspor atau dibagikan.

7. Berbagi dan penjualan data

BossPo tidak menjual data pengguna. BossPo tidak membagikan data pesanan kepada pihak lain secara otomatis. Data hanya dapat diteruskan ketika pengguna sendiri menjalankan fungsi berbagi, membuka WhatsApp, mengekspor file, atau memilih aplikasi tujuan lainnya.

8. Iklan dan pelacakan

Versi aplikasi BossPo yang berlaku saat kebijakan ini diterbitkan tidak menggunakan data pesanan untuk iklan bertarget dan tidak memasang sistem analitik pihak ketiga untuk membuat profil perilaku pengguna.

9. Keamanan data

BossPo dirancang untuk menyimpan data utama secara lokal dan hanya memberikan data kepada aplikasi lain melalui tindakan pengguna. Pengguna disarankan menjaga keamanan perangkat, kunci layar, file backup, serta file laporan yang telah diekspor.

10. Retensi dan penghapusan data

Data lokal disimpan sampai pengguna menghapusnya melalui fitur aplikasi, menghapus data aplikasi melalui pengaturan Android, atau menghapus aplikasi dari perangkat. File backup dan file laporan yang sudah disimpan di luar aplikasi harus dihapus sendiri oleh pengguna dari lokasi penyimpanannya apabila tidak lagi diperlukan.

11. Akun pengguna

BossPo pada versi ini tidak menyediakan sistem pembuatan akun pengguna di server BossPo. Oleh karena itu, tidak ada akun online BossPo yang perlu diminta untuk dihapus.

12. Privasi pelanggan yang datanya dicatat

Pengguna BossPo bertanggung jawab memastikan bahwa pencatatan nama, nomor WhatsApp, dan informasi pelanggan dilakukan secara wajar dan sesuai kebutuhan usaha. Pengguna juga bertanggung jawab menjaga data pelanggan yang tersimpan pada perangkatnya.

13. Perubahan kebijakan

Kebijakan ini dapat diperbarui apabila fitur BossPo atau cara pemrosesan data berubah. Tanggal pembaruan akan dicantumkan pada halaman ini.
